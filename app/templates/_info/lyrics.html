Lyrics — Standard vs Karaoke, LRC vs TTML

Heads up: Apple gates lyrics behind a valid Media User Token. If lyrics fail to download, that's almost always the problem — refresh the token (see the guide in the Authentication section above).

Don't expect karaoke timing inside the Apple Music app itself.

The Apple Music desktop / iOS / Android apps only render lyrics for tracks streamed from Apple's catalog. A track you've downloaded with this tool and added back into your Apple Music library shows up as a local file — the app deliberately won't load Apple's hosted lyrics for it, and it ignores embedded TTML / sidecar .ttml files. So even with karaoke (syllable-synced) lyrics enabled here, you'll see plain or no lyrics inside Apple Music.

To actually use the karaoke timing, play the file in something that honours TTML/LRC: foobar2000, Symfonium, Poweramp, Plexamp, Music Presence, or anything VLC-based with a lyrics plugin. The timing data is in the file — the Apple app just chooses not to read it for non-streamed content.

Lyrics Type

TypeGranularityBest for
lyricsline-by-lineDefault. Same as Spotify-style scroll: highlight one full line at a time. Works in every lyrics-aware player.
syllable-lyricsword / syllable"Sing along" mode. Each word lights up as it's sung. Only Apple Music itself, Music Presence, and a handful of players actually render this; everywhere else it falls back to line-by-line.

Lyrics Format

  • lrc — classic [mm:ss.xx]Line timestamps. Universal: Plex, Jellyfin, Poweramp, Symfonium, Yatse, foobar2000, every car deck. Pick this for "just works".
  • ttml — Apple's rich XML format. Mandatory if you chose syllable-lyrics — LRC can't carry word-level timing. Most players still recognise it; the unaware ones just ignore the file.

The Karaoke preset on the Download page automatically pairs syllable-lyrics + ttml; the Standard preset pairs lyrics + lrc. You only need to set these here if you want a custom combo as the default.

Embed vs sidecar

  • Embed Lyrics — writes lyrics into the audio file's metadata (USLT / \xa9lyr). Survives file moves; some players prefer this.
  • Save Lyrics File — drops a separate .lrc / .ttml next to the audio. Required if your library indexer reads sidecars (Plex needs this for some lyrics scanners).

Enabling both is the safest choice: cheap on disk, maximises compatibility.

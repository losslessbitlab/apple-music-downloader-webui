When to enable post-download conversion

By default the queue leaves Apple's container alone — ALAC stays in .m4a, Atmos stays as Atmos, AAC stays AAC. Turn on Convert After Download only when your library player insists on something else.

TargetLossless?Use case
flacyesRe-wrap ALAC as FLAC for libraries that won't read m4a (Roon, Lyrion / Logitech Media Server, older Sonos).
mp3noHard requirement for car decks & legacy MP3 players. ~30–40% smaller; quality loss baked in.
opusnoBest perceptual quality per byte. Great for phones / mobile; weak compatibility with older gear.
wavyesEditing / DAW import. Untagged and huge; not a library format.
copy–No re-encode; just re-mux. Use to fix container metadata without touching the audio stream.

Important toggles

  • Keep Original — saves both files. Sane default while you're experimenting; turn off later to save disk.
  • Warn / Skip Lossy→Lossless — warns or hard-skips a conversion that would pretend to upgrade quality (AAC→FLAC is meaningless). Leave both on.
  • Check / Delete Bad ALAC — runs the upstream ALAC sanity-checker after each download and optionally trashes corrupted files. Catches rare Apple CDN serve-errors.

Hooking up Plex / Jellyfin / Discord / ntfy

Both fields are optional. Leave blank to disable that hook. Both fire only on a successful download (failed jobs never trigger them).

Library Scan URL (HTTP GET)

Hit once per successful job. Use this to rescan your media library so newly-downloaded tracks appear without manual intervention.

  • Plex: http://<plex-host>:32400/library/sections/<sectionId>/refresh?X-Plex-Token=<your-token>
  • Jellyfin: http://<jellyfin-host>:8096/Library/Refresh?api_key=<api-key>
  • Emby: identical to Jellyfin (/Library/Refresh).
  • Navidrome: http://<host>:4533/api/scan?api_key=<key>

Completion Webhook (JSON POST)

Receives a JSON body so you get a notification (or pipe events into automations). Body shape:

{
  "url": "https://music.apple.com/us/album/…",
  "format": "ALAC",
  "quality": "ALAC 48 kHz / 24-bit",
  "save_folder": "/srv/music/AM-DL downloads/…",
  "duration_seconds": 47.2,
  "title": "Album Name",
  "artist": "Artist Name"
}
  • Discord: the bare webhook URL works as-is (Discord ignores unknown fields). For nicer formatting, run it through your own relay.
  • ntfy.sh: use a topic URL like https://ntfy.sh/your-topic. Body lands as the notification text.
  • Home Assistant / Node-RED: point at your webhook trigger; parse the JSON in the flow.

Both endpoints are called with a 5-second timeout and a single retry. They are fire-and-forget — a webhook outage never blocks the queue.

Cover-art options — what to pick

Cover Size

Resolution requested from Apple ({w}x{h}bb.jpg). 5000x5000 is the maximum Apple actually serves; you'll usually get 3000–5000 back depending on the asset. Lower it (e.g. 1400x1400) only if you embed art into AAC files and need to keep file size tight.

Cover Format

Format~MBWhy pick it
jpg0.5–2Default. Best compatibility for embedding in m4a/flac. Lossy but visually indistinguishable from PNG at the artwork sizes Apple ships.
png5–15Lossless. Costs ~10× the size for zero visible gain on artwork. Use only if your tagger normalises to PNG anyway.
originalvariesWhatever Apple's CDN returns (usually JPG). Skips re-encoding entirely; useful for archival snapshots.

Embed vs Sidecar

  • Embed Cover Art — writes the image into each audio file's metadata. Plays everywhere; survives moves.
  • Save Artist Cover — drops folder.jpg + an artist hero alongside the audio. Plex / Jellyfin / Kodi all pick these up automatically.
  • Save Animated Artwork — saves the short motion-poster MP4 Apple ships for some releases (mostly recent pop / hip-hop). Adds ~5–15 MB.
  • Emby Animated Artwork — renames the file to Emby's expected pattern (backdrop.mp4) instead of Plex's. Toggle to match your media server.

Tag suffixes, sort tags, iTunes IDs — what to enable

Filename suffixes

Appended to song / album filenames so you can grep your library for content type. Examples: [E] = explicit, [C] = clean (radio edit), [M] = Apple Master / Mastered for iTunes. Leave blank to skip the suffix entirely. Most users keep the defaults; they're cosmetic.

Sort Order Tags

Writes artistsort / albumsort / titlesort tags so libraries sort "The Beatles" under B and not T. Most modern players (Plex, Jellyfin, Roon, Symfonium) honour these. Leave on.

iTunes ID Tag

Embeds Apple's catalog identifiers (cnID, plID, atID) so your taggers and dedup tools can recognise the file as "the official Apple Music release of X". Useful when matching against MusicBrainz / Apple Music libraries.

Playlist-specific options

  • Use Song Info for Playlist — tags each track with its album metadata (year, original album name, track-of-N) instead of playlist metadata. Recommended ON: makes playlist-downloaded tracks behave normally in your library; OFF gives every track album = "My Playlist" which collapses your library view.
  • Download Album Cover for Playlist — pulls each track's real album art instead of the playlist's collage. Pairs nicely with the option above.

Heads up — downloading a playlist saves individual song files, not a single playlist.

Apple Music playlists come down as one m4a per track in {PlaylistName}/. There is no .m3u8 / .xspf sidecar by default. If you import that folder into MusicBrainz Picard or Mp3tag for full metadata clean-up, those tools will scatter the songs back into Artist/Album/… folders unless you tell them not to. Check the "move to library" / "rename based on tags" options before clicking apply on a playlist batch.

Workaround: enable Use Song Info for Playlist + Download Album Cover for Playlist above, then in your tagger turn OFF auto-rename and only fill missing tags. The files stay in your {PlaylistName}/ folder.

Want richer metadata than what Apple ships?

Two excellent (free) post-processors that pair well with this tool:

  • MusicBrainz Picard — cross-platform, AcousticID-based fingerprinting, fills in MusicBrainz IDs, original release dates, label info, work / recording / composer credits. Best for "I want my whole library to look like a discography".
  • Mp3tag (Windows / macOS) — faster manual editor, scriptable Actions, online sources include MusicBrainz, Discogs, Beatport, Apple Music itself. Best for tweaking individual albums or applying a custom naming scheme.

Both will recognise files this tool produces (m4a / flac / mp3) and keep the cover art Apple already embedded.

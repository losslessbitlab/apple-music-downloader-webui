What goes in Language & Storefront?

Safe to leave both fields blank. The downloader auto-detects from the URLs you queue (every Apple Music URL embeds the storefront, e.g. /ro/album/... = Romania). Override only if you specifically want to force a different region.

Language

BCP-47 tag used for metadata strings (track titles, artist names, album notes) when Apple has translated versions. Common values: en-US, en-GB, ja-JP, ro-RO, de-DE. Leave blank to use the language Apple's metadata API serves your account by default.

Storefront

Two-letter ISO country code matching your subscription region: us, jp, ca, ro, gb, etc. Different storefronts can publish different masters / region-locked content. The downloader follows whatever storefront is in the URL, so this is only used as a fallback when a URL doesn't carry one.

Heads up: queueing a URL whose storefront doesn't match your subscription region usually still works for catalogue browsing, but downloads can fail with Unavailable in your storefront. If that happens, switch storefront here OR open the album in your own region's URL and queue that instead.

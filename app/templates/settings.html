{# === Media User Token guide — collapsible === #}
How do I get a Media User Token?

The Media User Token is a 200+ character string tied to a logged-in Apple Music subscription. You only ever need to grab it once. It expires after a few months or whenever Apple invalidates your session — at which point lyrics, AAC-LC and music-video downloads start returning Unavailable and you fetch a fresh one.

  1. In a desktop browser (Chrome / Edge / Firefox), open music.apple.com and sign in with an account that has an active Apple Music subscription.
  2. Play any track or playlist for a few seconds so Apple actually issues the cookie.
  3. Open DevTools — F12 or Ctrl+Shift+I (⌘⌥I on macOS) — and switch to the Console tab.
  4. Paste the one-liner below and press Enter. Your token is now on the clipboard.
  5. Paste it into the Media User Token field above and click Save.
{# Yellow info callout — "What is this script doing?" #}

What does this script actually do?

It just reads the media-user-token cookie that Apple Music's web player drops on you after sign-in, and copies it to your clipboard via copy() — a built-in DevTools console helper. Nothing leaves your browser, nothing is sent over the network, nothing is stored. The whole thing is one expression and you can paste it as-is into any modern browser console.

If you'd rather grab the value by hand: open DevTools → Application tab → Cookies → https://music.apple.com → copy the value of media-user-token. 

copy(document.cookie.split('; ').find(c => c.startsWith('media-user-token=')).split('=')[1])

If the console errors with Cannot read properties of undefined, you aren't signed in yet or the cookie hasn't issued — play any track for a few seconds and re-run. Treat the token like a password; never share it.

{# === Quality preference chain (alac-rip web UI extension) === #}

Quality Preference Chain active

First entry the asset supports wins. Drives --alac-max for every queued job and seeds the in-modal chain editor. Per-item Cap dropdowns > in-modal chain > this saved chain.

Comma- or space-separated. The first one the album/track actually has wins. Default: 48000, 44100, 96000, 192000.
Recommended for most consumer hardware: keep 48000 first (24-bit/48 kHz; full audible spectrum, modest size).

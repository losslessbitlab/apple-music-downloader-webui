# Support

## Before asking for help

Check the README troubleshooting section first.

Useful checks:

```bash
python3 --version
git status --ignored
sudo python3 main.py
```

In the Web UI, open **System Health** and download the diagnostics bundle if you need to report a problem.

## What to include

When asking for help, include:

- Linux distribution and version.
- Whether you are using native Linux, a VM, or WSL2.
- Python version.
- Browser.
- Startup command.
- Redacted terminal output.
- Redacted diagnostics ZIP when relevant.

## Do not include

Never share:

- Apple ID password.
- Media User Token.
- Authorization token.
- `.credentials`.
- Unredacted `config.yaml`.
- Private webhook URLs.
